# Smart Attendance Analyzer (CLI)

## 📌 Description
A simple command-line tool that helps students track attendance and calculate safe bunk limits or required classes to maintain 75% attendance.

## 🚀 Features
- Calculate attendance percentage
- Find how many classes you can bunk
- Find how many classes you need to attend
- Stores data using CSV

## 🛠️ Tech Used
- Python
- CSV File Handling

## ▶️ How to Run

```bash
python main.py
